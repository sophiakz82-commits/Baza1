# Telecom Project

Веб-реестр телекоммуникационных проектов и инфраструктурных объектов. Сайт работает как статическая страница: отдельный сервер или установка программ не нужны.

## Публикация на GitHub Pages

1. Войдите в [GitHub](https://github.com/) и нажмите **New repository**.
2. Назовите репозиторий, например `telecom-project`. Для простого старта выберите **Public**.
3. Создайте репозиторий и добавьте в него **содержимое этой папки**: `index.html`, `styles.css`, `app.js`, `.nojekyll`, `README.md` и папку `.github/workflows` вместе с файлом `deploy.yml`. Не загружайте ZIP как единственный файл: GitHub Pages должен видеть `index.html` в корне репозитория.
   - Через браузер: на странице пустого репозитория выберите **Add file → Upload files**, перетащите файлы и папку `.github`, затем нажмите **Commit changes**.
   - Если скрытая папка `.github` не отображается в окне выбора файлов, создайте файл прямо на GitHub: **Add file → Create new file**, задайте имя `.github/workflows/deploy.yml` и скопируйте содержимое из этого проекта.
4. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите источник **GitHub Actions**.
5. Откройте вкладку **Actions** и дождитесь завершения запуска **Deploy to GitHub Pages**. После успешного запуска ссылка появится в **Settings → Pages**. Обычно она имеет вид `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

При каждом последующем изменении файлов и сохранении их в ветку `main` сайт будет обновляться автоматически. Workflow уже находится в `.github/workflows/deploy.yml`.

## Загрузка исходных данных

На сайте нажмите **Загрузить файл**. Поддерживаются Excel (`.xlsx`, `.xls`), CSV/TSV и JSON. Заголовки на русском и английском сопоставляются автоматически; если адрес не распознан, можно выбрать нужный столбец вручную.

Данные импортируются в локальное хранилище браузера пользователя и не отправляются в репозиторий или на сервер. При открытии сайта с другого устройства или браузера записи нужно импортировать снова. Файлы Excel читаются через библиотеку SheetJS с CDN и требуют подключения к интернету.
